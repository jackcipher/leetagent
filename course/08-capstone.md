# 毕业项目：论坛研究 Agent

[课程目录](README.md) · [完整项目讲义](../capstone/README.md)

## 项目目标

把前七课的能力组装成一个离线可测试的研究 Agent：它能够查询论坛数据、检索相关内容、生成带来源的报告，并检查引用是否真实存在。

## 项目里程碑

| 里程碑 | 配套项目 | 主要能力 |
|---|---|---|
| M1 | [论坛工具](../capstone/m1_forum_tools/) | 工具定义、参数解析、数据访问 |
| M2 | [研究索引](../capstone/m2_research_index/) | 切块、检索、去重与 Top-K |
| M3 | [研究 Agent](../capstone/m3_research_agent/) | ReAct、来源引用与幻觉检测 |

## 建议顺序

1. 完成 M1，让 Agent 能稳定访问论坛数据。
2. 完成 M2，建立不依赖外部服务的离线检索。
3. 完成 M3，把工具、检索和 Agent 循环组装起来。
4. 使用 `go test -tags solution ./capstone/...` 验证参考实现环境。

## 完成标准

能够输出一份带来源的研究报告；报告中的每个引用都能通过工具重新查询并验证，而不是由模型凭空生成。
